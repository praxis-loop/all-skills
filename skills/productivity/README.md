# productivity

`productivity` 用于个人计划、复盘、习惯、知识整理和效率流程。

常见 domain：

- `planning`：日计划、周计划、目标拆解。
- `review`：复盘、总结、改进计划。
- `personal-routines`：个人例行流程、习惯和提醒。
- `knowledge-management`：笔记整理、知识库维护、资料归档。
- `communication`：职场沟通、向上管理、消息与会议表达。
- `collaboration`：会话交接、协作流程。
- `feedback`：方案打磨、追问审视。
- `reading`：阅读、知识蒸馏。

当前已启用 domain：

- `collaboration`
- `communication`
- `feedback`
- `reading`
- `review`
- `knowledge-management`
